# STELLARIS | Aerospace Data Archive

Welcome to the **STELLARIS** repository. This project is a premium, immersive front-end web application that serves as a comprehensive aerospace data archive. It is designed with a dark-mode-first, high-contrast aesthetic and features interactive elements to provide a rich user experience exploring the cosmos.

## Features

- **Immersive Hero Section**: Parallax background with dynamic text scrambling effects.
- **Cosmic Map (Orrery)**: Interactive galactic map visualizing the Local Supercluster with live telemetry simulations.
- **Morphological Classification**: Horizontal scrolling gallery showcasing different galaxy types (Spiral, Elliptical, Irregular).
- **Historical Timeline**: A vertical timeline of significant space observatory deployments.
- **Dynamic Footer**: A twinkling star field implemented using the HTML5 Canvas API for an infinite, interactive animation loop.
- **Premium UI/UX**: Utilizes glassmorphism, micro-animations, noise overlays, and a custom cursor for a state-of-the-art feel.
- **Responsive Design**: Fully responsive layout adapting to various screen sizes.

## Technologies Used

- **HTML5**: Semantic structure.
- **Tailwind CSS**: Utility-first CSS framework for styling and layout (via CDN for rapid development/prototyping).
- **JavaScript (Vanilla)**: For interactions, animations, custom cursor, scroll effects, and the Canvas-based star field.
- **Google Fonts**: Orbitron, Outfit, Space Mono, and Space Grotesk for typography.
- **Google Material Symbols**: For scalable iconography.

## Getting Started

To view the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/Avinay45/-cosmic_observatory_odyssey_website.git
   ```
2. Open the project folder.
3. Serve the directory using a local web server (e.g., Live Server extension in VS Code, or Python's `http.server`):
   ```bash
   python -m http.server 8000
   ```
4. Open your browser and navigate to `http://localhost:8000`.
